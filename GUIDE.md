# Reader's Guide — Awesome-Hacking

## What this project is

Awesome-Hacking is a **collection of awesome lists for hackers, pentesters and
security researchers**. It is a meta-index: instead of hosting tools itself, it
points you to the best specialised "awesome list" for each corner of offensive
and defensive security — from bug bounties and CTFs to OSINT and malware
analysis.

## How the content is organised

Almost everything lives in a single file, [`README.md`](README.md), split into
two tables:

- **Awesome Repositories** — the main index. Each row is a topic area with a
  one-line description and a link to that topic's own awesome list. Areas
  covered include Android Security, AppSec, Asset Discovery, Bug Bounty,
  Cellular Hacking, CI/CD Attacks, CTF, DevSecOps, Fuzzing, Honeypots,
  Incident Response, Industrial Control System Security, IoT and Hardware
  Security, Malware Analysis, OSINT, Password Cracking, Pentest, Prompt
  Injection, Red Teaming, Reversing, Social Engineering, Static Analysis,
  Threat Intelligence, Vehicle Security, Web Hacking, Web3 Security and YARA.
- **Other Useful Repositories** — a second table of adjacent collections that
  do not fit the main categories, such as AI Security and Annual Security
  Reports.

Supporting files at the repository root:

- `contributing.md` — how to suggest a list or improvement.
- `LICENSE` — CC0-1.0; the content is public domain.
- `awesome_hacking.webp` — the banner image shown at the top of the README.

## How to use it

1. Open `README.md` and scan the **Awesome Repositories** table for your area
   of interest.
2. Follow the link in that row to the dedicated list, where the actual tools,
   tutorials and resources are catalogued.
3. If you know a list that belongs here, check `contributing.md` and open a
   pull request.

## About this standalone edition

This repository is a standalone edition of
[Hack-with-Github/Awesome-Hacking](https://github.com/Hack-with-Github/Awesome-Hacking),
converted from a fork into its own repository and enhanced in place. See
[`ENHANCEMENTS.md`](ENHANCEMENTS.md) for what this edition adds and
[`CHANGELOG.md`](CHANGELOG.md) for its version history (v1.0.0 upstream
baseline, v1.1.0 enhancements). All original content belongs to the upstream
contributors.
